#CoffeeCart Automation Testing

#Objetivo -
O projeto consiste na automatização de teste de compra, validação, remoção e preenchimento da "https://coffee-cart.app/". O Desafio foi proposto para avaliar a habilidade e desempenho dos alunos na utilização do cypress.

#Tecnologia & Extensões usadas -
JS, Cucumber, Node.js, Cypress, Xpath, Faker.js

3 - Pré-requisitos & Como rodar o projeto -
Instalar o node.js; Instalar o VScode; No VScode, adicionar os pluggins de "Cucumber(Gherkin) full suport"; 
No VScode, digite "git init". Instale pelo terminal o Cypress (“npm install cypress --save-dev”).

5 - Organização do projeto - 
Seguindo a orientação recebida em aula sobre a boa prática de manter um idioma principal e uma linguagem clara, priorizei o uso do Português (PT-BR) em todo o desenvolvimento da automação. Evitei o uso de gírias e de termos em inglês sempre que não fossem obrigatórios pela sintaxe da ferramenta ou da API, aplicando essa padronização tanto na nomenclatura de variáveis quanto nos nomes dos arquivos. O objetivo foi garantir que o código seja legível e siga um padrão técnico e organizado.
